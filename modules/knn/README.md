## 学生要带走什么

**明确问题 → 规划采集 → 检查与清洗 → 划分数据 → 建立 KNN → 验证 → 改进。**

AI 帮你写程序；你决定哪些数据可信、如何验收。我们只根据重量和直径判断苹果、橙子、梨，不做照片识别，也不需要训练大语言模型。

## 课前准备

沿用原项目的本地 Jupyter 环境，Python 3.10 或更新版本。从项目根目录启动 Jupyter，打开新 Notebook，按顺序运行。模型仅使用 Python 标准库，无需额外安装机器学习库，不调用 API。随项目分发完整文件夹，不能只发送 Notebook：它需要 `modules/knn/` 下的代码和 CSV。

教师先用“重启内核并运行所有单元格”走一遍。讲稿延续原课方向键翻页、N 键教师备注的操作。课堂代码已备好，学生卡住可以回到原单元格；把时间用在判断数据和验证 AI 的修改上。

## 真实数据怎么收集

1. **定义目标**：在相近的采集条件下，根据重量与最大横向直径区分这三种水果。标签由实物、包装或可靠来源核对，不由模型猜。
2. **准备工具**：电子秤、尺子或卡尺、编号贴纸、采集表。秤先归零；重量按克记录，直径按厘米记录。直径指最宽横截面的宽度，不是周长，也不是高度。
3. **分组采集**：课堂目标每类至少 20 颗不同水果，覆盖不同大小、成熟度和批次。这个数量只是练习起点，不是“足以可靠部署”的标准。
4. **统一编号**：例如 G1-001。同一颗水果复测沿用同一编号；不同组不能复用编号。不要把复测当成新样本。
5. **记录来源**：另建采集日志，记录日期、组别、商店/批次、器具、测量协议和标签核对人。无需记录个人敏感信息。原始表保留，只在副本里更正。
6. **诚实判断代表性**：只采集一家店的一箱苹果，模型未必能处理另一家店。真实扩展实验可按批次或商店整体留出测试集；本示例的分层随机划分只演示同分布样本评估。

## 清洗前先定规则

空白、不能解析的数字、非有限数、无效标签、无法确定的单位和超出本练习测量范围的值必须进入审计记录。范围规则是本练习的预先约定，不是所有水果的自然定律；真实异常应回查或复测，不能为了提高准确率随便删。

已明确记录的单位可以换算；未知单位不能猜。完全相同的同编号记录只保留一份；同编号却有冲突的记录应一起隔离、等待复核。缺失值本课采取隔离并回查的简单策略，真实任务若需要均值或中位数填补，只能在训练集上估计参数。

本课允许在划分前执行预先固定的格式修正、单位换算和按实体去重。任何从数据估计的处理——例如标准化的均值/标准差、缺失填补、阈值调优——必须遵守训练边界。

## 模型讲法与验收

- **KNN**：在标准化后的特征空间里，找到距离最近的 K 个训练样本，以票数最多的类别为预测。K 是邻居数，不是类别数；三分类即使 K 为奇数也可能平票。
- **尺度**：克与厘米数值跨度不同，直接计算距离可能让重量支配结果。标准化使用训练集的均值和标准差；验证、测试和新水果沿用同一组参数。
- **分工**：训练集提供邻居；验证集在 K=1、3、5 中选 K；测试集只做最后评估。固定随机种子保证课堂结果可复现，不能反复换种子挑好成绩。
- **评估**：报测试集样本数、正确数、准确率、混淆矩阵，并与“始终猜训练集最多的类别”比较。看错在哪一类，不能只报一个百分比。
- **解释**：展示新水果的邻居编号、真实类别与距离。票数占比不是经过校准的概率。模型遇到香蕉也会被迫猜三类之一，因此演示输入应限定在这三类和约定测量范围内。
- **改进**：可以在训练/验证阶段试新特征、不同 K 或补充数据。看完测试结果再调整，原测试集就不能继续被当作独立的最终成绩；应准备新的独立留出数据。

模拟数据仅用于练习流程，故意包含类别重叠与脏记录。它的成绩不能证明真实水果识别能力。模型训练在这里主要是保存训练样本及缩放参数，预测时才进行距离计算和投票。

默认数据与 seed=42 的教师核对值：82 条原始记录，72 颗保留水果；训练/验证/测试为 42/15/15；K=1、3、5 的验证准确率约 66.7%、80%、80%，并列取较小值后 K=3；测试 12/15 正确，基线 5/15。学生换数据后结果可以不同，不能为了凑到这些数字去改标签或删样本。

确定性规则：邻居距离完全相同时按编号排序；类别票数相同时，优先选该类别邻居总距离较小的，仍相同则按英文标签字母顺序。基线的训练集类别数量并列时也按标签字母顺序。

## 教师追问与参考回答

| 追问 | 回答要点 |
|---|---|
| 把同一颗苹果称十次，算十颗吗？ | 不算；会重复计算同一实体，跨集合重复还会泄漏。 |
| 为什么不把 fruit_id 也当作特征？ | 编号只是追踪实体，通常没有可推广的分类含义。标签更不能放进特征。 |
| 模型预测错了，就把标签改成预测值？ | 不行；标签应回查真实来源，预测不是事实。 |
| 准确率提高就一定做对了吗？ | 先查泄漏、评估规模、类别分布和数据代表性。 |
| K 越大越好吗？ | 不一定；更平滑也可能掩盖局部差别，用验证集比较。 |
