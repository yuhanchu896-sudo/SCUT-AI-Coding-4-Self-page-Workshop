What if the Agent could drive more of the loop?

From AI Coding to Agentic AI Coding

AI Coding

人推动流程

Prompt → AI 修改 → 你运行
→ 你检查 → 再提要求 ↺

Agentic AI Coding

Agent 接手更多步骤

目标 → 读取 → 修改 → 运行
→ 检查 → 修复 → 验证
Skill
这类事情怎么做好
Harness
怎么把事情完整做完
并验证

AI Coding ≠ AI 替你思考

How we write code changes.
The need to think does not.
